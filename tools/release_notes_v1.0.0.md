## 企业信用一键截图工具 v1.0.0

在 **8 个**政府/司法公开平台上按单位或人员统一检索、批量截图的桌面工具。覆盖 **30 类**信用记录，支持浏览器界面与独立软件窗口两种形态。

### 下载

| 文件 | 说明 |
|---|---|
| `企业信用一键截图工具_安装包.exe` | Windows NSIS 安装包（80.1 MB），**已内置全部运行时依赖**，装完即用 |
| `界面预览.png` | 界面截图 |
| `使用说明.md` | 完整使用说明 |

安装后双击运行，只监听 `127.0.0.1`，浏览器界面与软件窗口均可用。

### 本版本要点

- **修复「跳过此步」失效**：控制流异常改继承 `BaseException`（原先被平台层几十处 `except Exception` 静默吞掉）、平台层等待改为可中断等待、节流期间不消费跳过信号。响应时延约 1 秒，只跳当前一项、不影响后续采集项。
- **新增 CNCA 体系查询**：输入企业名称 → 查询 → 认证结果综合查询 → 组织列表 → 证书列表截图 → 证书详细信息截图。
- **导航层增强**：支持按路径挑选链接与落地校验，避免从上级目录跳转时跳错页面。

### 使用注意

1. **认监委（CNCA）等站点需从上级目录跳转进入**，工具已内置该逻辑，直连易被判定为异常 IP。
2. **CNCA 的三处验证码是极验 v4**，打码服务不提供该题型，需要**人工点选**。工具会暂停并提示，完成后点【我已处理，继续截图】继续。
3. **凭据**保存在 `%APPDATA%\企业信用截图工具\凭据.ini`（仅本机，明文），日志中账号脱敏、密码不进日志。
4. **打码服务**使用 YesCaptcha 兼容接口，API Key 留空则不发任何请求，全部回落人工。

### 从源码构建

```bat
python main.py                          :: 源码运行
python tools/build_exe.py               :: 生成 dist/企业信用截图工具/
python tools/build_installer.py         :: 生成 NSIS 安装包
```

依赖 Python 3.13 + FastAPI ≥ 0.121 + Playwright。未安装 Playwright 自带浏览器时，工具会自动改用本机 Edge 并通过 CDP 接管。
