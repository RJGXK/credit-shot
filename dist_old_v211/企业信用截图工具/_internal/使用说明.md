# 企业信用一键截图工具

按 8 个政府/司法公开平台采集信用记录，支持**单位 / 人员两种互斥的查询模式**，
以及四种出图形态：**浏览器原生整页截图**（不拼接、不后期合成）
与 **原生整页 + 右下角 Windows 日期/时间弹窗**。

```
credit_shot/
├── main.py              程序入口：起本地服务 + 开浏览器
├── launcher.pyw         无控制台入口（pythonw 执行），异常写 启动错误.log
├── config.py            站点/采集项目录、默认参数
├── engine.py            编排器：组装部件、调度主体×采集项、汇总结果
│
├── core/                通用能力（与「哪个站点」无关）
│   ├── browser.py       浏览器会话：启动 Edge/Chrome + CDP 接管 + 收尾
│   ├── page.py          页面动作原语：填值 / 点击 / 等待
│   ├── nav.py           站点进入策略：上级目录跳转链、跳转容错
│   ├── capture.py       截图与合成：信息条、日期面板、整页截图
│   ├── captcha.py       验证码处理（引擎侧：自动识别 + 刷新重试 + 提交）

│   ├── subject.py       查询主体的解析与判定
│   ├── control.py       界面与引擎之间的控制信号
│   ├── result.py        单个采集项的结果
│   └── errors.py        异常体系（控制流异常 / 业务异常）
│
├── platforms/           各站点采集逻辑（一个站点一个模块）
│   ├── base.py          处理器基类 + 分派表
│   ├── credit_china.py  信用中国（信息公示 + 专项查询）
│   ├── shixin.py        失信被执行人（zxgk.court.gov.cn）
│   ├── ccgp.py          中国政府采购网
│   ├── mohurd.py        住房和城乡建设部
│   ├── plap.py          军队采购网
│   ├── gsxt.py          国家企业信用信息公示系统

│
├── auth/                账号凭据与自动登录
│   ├── credentials.py   凭据模型、凭据.ini 读写、账号脱敏

│
├── web/                 本地 Web 界面
│   ├── server.py        FastAPI 应用、路由挂载、静态资源
│   ├── api.py           REST 端点 + 任务管理（后台线程跑引擎）
│   ├── events.py        事件总线（SSE 推日志与状态）
│   ├── models.py        请求/响应模型
│   └── static/          前端（原生 HTML/CSS/JS，无构建步骤）
│
├── desktop.py           Windows 特有：任务栏时钟定位、日期面板抓取
├── selftest.py          逻辑自检（20 项，不需要浏览器与 API Key）
└── tools/               开发自检脚本（见下）
```

分层规矩：

* `platforms/` 只写「这个站点怎么查」，不碰浏览器与截图；
* `core/` 只写通用能力，不含任何站点知识；
* `engine.py` 只做编排，不写业务细节；
* `web/` 只做界面，不写站点细节。

界面与引擎之间只有两个接口：**REST 下指令**、**SSE 收日志**，
所以换界面（桌面版/网页版）不用动引擎。

## 使用

### 安装版（推荐给最终用户）

`dist\企业信用一键截图工具_安装包.exe`（约 80 MB）是**可直接分发的安装包**，
目标电脑**不需要装 Python**，双击安装即可。

| 步骤 | 说明 |
|---|---|
| 1 | 双击 `企业信用一键截图工具_安装包.exe`，按提示选安装目录 |
| 2 | 装完桌面会出现「企业信用一键截图工具」快捷方式 |
| 3 | 双击它：弹出**软件窗口**（不是浏览器），界面在里面直接操作 |
| 4 | 关掉软件窗口 = 退出程序（不会留下后台进程） |

安装说明：

- 安装包内置了 Python 运行时、Playwright 驱动、pywin32，**无需联网、无需装依赖**。
- 安装位置默认 `C:\Program Files\企业信用一键截图工具`，可在安装时改。
- 开始菜单里有「企业信用一键截图工具 / 使用说明 / 卸载」三项。
- 卸载只删程序文件，**不会删** `%APPDATA%\企业信用截图工具\` 里的账号配置与截图，
  避免误删用户数据；要彻底清理手动删那个目录即可。
- 需要电脑上已装 **Edge 或 Chrome**（程序会自动探测，不装浏览器会提示）。
- 配置与日志：`%APPDATA%\企业信用截图工具\`（`凭据.ini`、`运行.log`）。
- 界面右下角有「**用浏览器打开**」按钮：想在浏览器里操作（比如放到第二块屏幕）时点它。

**重复双击的行为**：程序已经在运行时，再双击快捷方式**不会**起第二个服务，
而是把已开的软件窗口顶到前台（找不到窗口才退回到用浏览器打开）。

> 安装版与源码版可以共存：安装版用独立的互斥体做单实例，不会被源码版占用的端口挡住。

### 界面自适应

界面在浏览器和软件窗口里都是**响应式**的，窗口随便缩放都不会裁切或溢出：

| 窗口宽度 | 表现 |
|---|---|
| ≥ 1180px | 左右两栏并排（左栏宽度随窗口浮动） |
| 900–1180px | 两栏仍并排，但表单标签与控件改为两行排布 |
| < 900px | 自动改为上下单栏，采集清单与日志各占一块，可纵向滚动 |

底部工具栏、状态栏、凭据弹窗都会随宽度重排；长文字（站点名、采集项名称）
用省略号截断，鼠标悬停仍能看到全名。

**站点快速跳转条**：采集清单卡片头部下方有一排小按钮
（信用公示 / 信用专项 / 政府采购 / 住建部 / 军队采购 / 公示系统 / 裁判文书），
点一下就滚动到对应站点，不用一路滚到底找「中国裁判文书网」。

### 源码版（开发/本机调试）

**双击 `启动.vbs`** —— 无命令行黑框：起一个只监听 `127.0.0.1` 的本地服务，
并自动用系统默认浏览器打开界面（`http://127.0.0.1:<端口>/`）。

> 服务只绑定本机回环地址，不对外网暴露；关掉启动它的那个命令行窗口即结束服务。

首次使用先双击 `启动.bat` 装依赖（需要 Python 3.9+ 与 `playwright`、`Pillow`、
`pywin32`、`fastapi`、`uvicorn`）：

```
pip install playwright pillow pywin32 fastapi uvicorn
```

> 源码版和安装版可以共存：两者都用同一套「单实例」判断，
> 先启动哪个就用哪个的界面，后启动的会直接打开已有界面而不再起第二个服务。

### 操作

1. 先在「查询主体」区顶部选**查询类型**（分段控件，点左半边=单位，右半边=人员）：

   | 查询类型 | 输入格式 | 含义 |
   |---|---|---|
   | **单位** | `企业名称|统一社会信用代码` | 查一个单位（企业 / 法人）。信用代码可留空，只写企业名称也行 |
   | **人员** | `人员姓名|身份证号` | 查一个人（自然人）。身份证号填 15 位或 18 位 |

   一行一个主体，**只填一个也行，填多行就是批量**。

   > 两种模式的名单范围不同，切换时下方列表会**自动置灰**不适用的采集项：
   > 单位模式 24 项可用（仅「安全生产严重失信主体名单（自然人）」不可用）；
   > 人员模式 10 项可用（安全生产自然人名单、失信被执行人、军队采购网 5 个名单、裁判文书网 3 类）。

2. 选好**图片保存目录**。
3. 浏览器选 Edge / Chrome；截图方式选四档之一（见下）。
4. **节流间隔**默认 30 秒（步骤与步骤、主体与主体之间各等一次，模拟正常使用频率，避免触发风控）。
5. 在「需要截取的内容」里按站点分组勾选（可点站点右侧「全选」，或右上角全选/全不选）。
6. 点【开始截图】。
7. 遇到验证码 / 滑块 / 登录时，工具会挂起并提示：
   - 在浏览器里人工完成 → 回窗口点【我已处理，继续截图】
   - 无法完成 → 点【跳过此步】
   - 整体中止 → 点【中止】
8. 点【打开输出目录】查看结果。

### 鼠标滚轮

两个长列表各自独立滚动，**滚哪边只动哪边**（Web 版由各自的滚动容器天然保证）：

| 光标位置 | 滚轮作用 |
|---|---|
| 停在「运行日志」上 | 只滚动日志内容，「需要截取的内容」面板纹丝不动 |
| 停在「需要截取的内容」上（含每一行复选框） | 只滚动采集项清单，运行日志不受影响 |
| 停在窗口其它位置 | 不做任何事 |

另外：你手动把日志往上翻之后，后续新产生的日志行**不会**把视图强行拽回底部；
想回到最新一行，把日志滚到底部即可（回到底部后又会自动跟随）。

### 四个运行按钮各管什么

| 按钮 | 什么时候可用 | 点了会发生什么 |
|---|---|---|
| **开始截图** | 空闲时 | 清空日志，按勾选项开跑；启动后本按钮变灰（防重复点击） |
| **我已处理，继续截图** | 运行中 | 引擎挂起等待人工处理时，按钮会**变蓝高亮**、右上角状态显示「等待处理」；此时点击即放行。引擎正在跑其它步骤时点击，指令会被记下，到下一个等待点自动生效 |
| **跳过此步** | 运行中 | 跳过当前这一步（通常是过不去的验证码），继续下一步 |
| **中止** | 运行中 | 立刻停止整轮任务，收尾关闭浏览器，界面复位 |

> 运行过程中按钮状态会跟随引擎真实状态变化；若工作线程意外崩溃，界面会自动复位并在日志里标红，不会出现「按了没反应、按钮永久变灰」的情况。

## 账号密码与自动登录

主界面右上角点【账号密码】打开设置面板，8 个平台各有一行：

| 列 | 说明 |
|---|---|
| 启用 | 关掉这一行＝不参与自动登录 |
| 账号 | 裁判文书网填**注册手机号**；其它平台填手机号/用户名 |
| 密码 | 默认掩码显示，点「显示」可临时看明文 |
| 平台 | 只读提示（支持自动登录：**中国裁判文书网**、**国家企业信用信息公示系统**；其余平台公开查询免登录） |

底部三个按钮：

- **保存到本地** —— 明文写进 `%APPDATA%\企业信用截图工具\凭据.ini`（含打码 API Key）。
  这是你主动保存的行为；不点就只在内存里，关掉程序即消失。
- **从本地载入** —— 把 `凭据.ini` 里的配置读回面板。
- **测试打码服务** —— 调打码服务查余额，确认 API Key 可用。

> 密码只进内存和本机文件，**日志里只打印脱敏账号**（如 `138****8000`），绝不打印密码原文。

**三条容易踩的规则**（2026-10 修复）：

1. **密码和 API Key 都不回显**（安全考虑）。已经保存过的，密码框显示
   「已保存（留空则不修改）」、Key 框同样提示 —— **留空表示不改，而不是清空**。
   所以改完账号密码后想保存，直接点【保存到本地】就行，不用把密码重新敲一遍。
2. **源码版与安装版共用同一个凭据文件**（都在 `%APPDATA%\企业信用截图工具\`），
   在一边配置另一边立刻生效，不会出现「明明保存了却不生效」。
3. **打码服务**：没配 API Key 时，所有图形验证码都会转人工处理，日志开头会写明
   「打码服务：未配置 API Key」；配了则显示「已启用」。
   【测试打码服务】在输入框为空时也会用**已保存的** Key 去测。

### 自动登录是怎么跑的

以中国裁判文书网为例：

1. 检索时发现未登录 → 点开右上角「登录」（SPA 渲染慢或站点抽风时自动重试，仍不行就刷新页面再来一轮）；
2. 等统一身份认证的跨域 iframe 加载出来（真机上同时存在「授权回调」和「扫码登录」两个同域 iframe，工具按**有没有密码框**挑中真正的登录表单那个）；
3. 用原生 setter 往 `手机号码` / `密码` 两个框里填值并派发 `input/change` 事件（Vue 受控组件必须这样才会收下）；
4. 点提交按钮 `div.login-button-container`（页面上还有「忘记密码」和国家区号下拉，按文字模糊匹配容易点错，所以按类名定位）；
5. 判定结果：成功 / 账号密码错误 / 需要验证码 / 未确认；
6. **登录成功后自动重新检索一次**——之前那次检索是被登录页拦下来的，结果是空的。

国家企业信用信息公示系统（gsxt）走另一套流程：

1. 先按「上级目录跳转」进入首页（见下一节），确保不是白页；
2. 点右上角「登录」弹出登录框；
3. 一次 `evaluate` 同时填 `#UserName`（手机号/身份证号）和 `#gsxtp`（密码），
   用原生 setter 赋值并派发 `input/change` 事件；
4. 提交后判定登录态；若弹出**极验点选**（`arms-retcode`）则转人工。

### 从上级目录跳转（不直连目标网址）

很多政务站点会对**直接输入网址**的访问判为「异常 IP」：

| 站点 | 直连症状 | 实际进入方式 |
|---|---|---|
| 国家企业信用信息公示系统 | 白页 + 瑞数「Environment Checking」 | 先开 `www.samr.gov.cn`，点「国家企业信用信息公示系统」链接跳入 |
| 信用中国 | HTTP 412 | 先开 `www.gov.cn`，点「信用中国」链接跳入 |
| 中国政府采购网 | HTTP 403 | 先开 `www.ccgp.gov.cn` 同域上级页，再点入 |
| 最高法失信被执行人网 | 偶发拦截 | 先开 `zxgk.court.gov.cn` 同域上级页，再点入 |

工具的实现（`core/nav.py`）：

- 每个站点在 `ENTRY_CHAINS` 里配了一条**入口链**：上级目录页 → 要点的链接关键词；
- 落地后**点击页面上的链接**（而不是 `goto` 目标网址），让浏览器像真人一样从上级目录跳过去；
- 站点自己跳到新标签页时（`target=_blank`）自动切到新标签页继续操作；
- 落地页会做「环境检测」时（标题含 Environment Checking）会等它放行，最多 40 秒；
- 跳转后校验 `location.host` 是否是目标站，**跳到别的站就换下一条入口链**；
- 整条链都失败才回落到直连，并记日志说明。

> 裁判文书网首页会自己从 `/` 跳到 `/website/wenshu/<随机ID>/index.html`，
> 这个自跳转会把 `page.goto` 打断并抛 `Navigation ... interrupted by another navigation`。
> 工具用 `core.nav.goto` 统一处理：**跳到哪算哪，不当失败**。

### 验证码：三种处理方式

| 场景 | 处理 |
|---|---|
| 配了打码 API Key 且该验证码属于支持的题型 | **全自动**：截图 → 送打码服务 → 填入 → 提交 |
| 没配 API Key，或题型不支持 | **半自动**：程序把账号密码填好并把光标带到验证码处，界面按钮高亮，你只补一个验证码，完成后点【我已处理，继续截图】，程序继续提交并判定结果 |
| 滑块 / 点选类验证码 | **人工**：打码服务官方题型里没有天艾点选和极验滑块，只能自己拖/点 |

> 裁判文书网登录用的是**天艾点选**验证码，所以这一站登录时基本需要人工过一次；
> 信用中国等站点的**图形码**可以交给打码服务全自动处理。

支持的题型（按 YesCaptcha 官方接口）：

| 题型 | 任务类型 |
|---|---|
| 图形验证码（图片英数字） | `ImageToTextTaskOcrBase` / `ImageToTextTask` |
| reCAPTCHA v2 | `NoCaptchaTaskProxyless` |
| hCaptcha | `HCaptchaTaskProxyless` |
| Cloudflare Turnstile | `TurnstileTaskProxyless` |

打码服务节点：国内 `cn.yescaptcha.com` 优先，国际 `api.yescaptcha.com` 备份，
某个节点连不上会自动切到另一个。API Key 留空时**一个请求都不会发**。

### 验证码刷新重试（图片第一次是空白的情况）

有些站点的验证码图片**第一次加载出来是空的 / 灰图**，刷新几次才出真图。
只识别第一次的话，送去识别的就是一张空白图，识别结果自然是空的。

工具的处理（`core/captcha.py`）：

1. 截验证码图片 → 送去打码服务；
2. 识别结果为空、或图片明显是纯色/空白 → **点一下「刷新」**换一张图，重新截图再识别；
3. 最多重试 **3 次**，每次都会在日志里写明「第 N 次识别为空，刷新后重试」；
4. 3 次都失败才回落人工，并在日志里说明原因。

> 注意：刷新会**换掉已经填好的验证码**，所以必须先识别成功再往输入框里填，
> 不能先填后识别。工具的顺序就是「识别 → 填入 → 提交」。

### 日期/时间弹窗是怎么抓的

浏览器原生截图只能画网页内容，画不出系统浮层，所以日期面板必须**抓真实屏幕**再合成。
难点在于**定位这块面板**——它由 Windows 用 DComp 渲染，没有独立的窗口句柄，
而且卡片高度会随内容变化（多一条通知就变高），硬编码坐标或按固定版式算都会错位。

工具的做法（**跨分辨率、跨缩放比例、跨 Windows 版本都自适应，且只读系统、不改任何设置**）：

1. 在右下角区域找到那行大字号时间 `HH:MM:SS`（字高 ≥13 DIP、右侧大片留白，特征极强）；
2. 用这条时间行带做**背景剖面**（每列取最亮像素，跳过字形笔画），向左找最近的
   **描边暗线** = 卡片左缘，向右找最远的描边暗线 = 卡片右缘；
3. 在卡片左缘内侧的空白列上，向上找描边暗线 = 上缘，从任务栏上沿往下找 = 下缘；
4. 每个候选时间行都做一次自校验（卡片尺寸是否合理、时间是否紧贴左缘），第一个通过的即采用；
5. 全部失败时退回「按 DPI 换算版式尺寸」的几何兜底框。

裁切结果按卡片圆角做透明遮罩，带柔和投影贴在页面右下角。

> 时钟位置是**动态定位**的（对任务栏右端做图像分析找时间文字块），托盘图标增减不会点偏；
> 弹出后会用「大字号时间」特征校验，确认弹的是日历而不是通知中心。

**「点了日期不弹出来」的三个原因和对策**（2026-10 加固）：

| 原因 | 对策 |
|---|---|
| 上一次的面板还开着 —— 状态是「已展开」，再点会**先收起** | 每次尝试前先调 `close_date_popup()` 关掉已有浮层 |
| 任务栏自动隐藏 —— 右下角根本没有时钟 | 先调 `wake_taskbar()` 把任务栏唤出来 |
| 点击落在时钟文字外侧 / 点到通知中心 | 图像分析给出**时间行 → 日期行**两个候选点，逐个试并用「大字号时间」特征校验；两个都不行再走 `Win+A` 快捷键兜底 |

整体流程：**关已有浮层 → 唤起任务栏 → 最多 3 轮重试**（每轮先试时间行、再试日期行），
3 轮都失败才回落到 `Win+A`；仍然失败则**只保留页面原图**并在日志里提示，
不会因为弹不出面板就丢掉整张截图。

> 面板区域检出后若尺寸不合理（宽或高 < 60px，多半是误检到别的东西），
> 同样只保留原图并说明原因。

## 关键行为说明

- **内容刷新才截图**：每一步都会等到站点真正返回查询结果（有数据行 / 明确的无记录文案 / 查询回执）才截图；
  等不到时按当前画面截图并在日志里标注「等待结果超时」。
- **会话共享**：住建部（12-15）只搜索一次并进入企业详情页，再逐个切 tab；
  军队采购网（16-20）只打开一次页面，再逐个名单查询；
  公示系统（21/23/24/25）只搜索一次并进入企业详情页，四个板块合成一张整页图；
  裁判文书网三类案件各自按 `s8` 参数单独导航，因此三张图内容互不相同。
- **公示系统整页图**：详情页左侧目录是 sticky 定位，Playwright 展开整页时会反复滚动拼接导致超时；
  工具会在截图前把 sticky / fixed 元素临时改成 static，截完再恢复（实测 0.6 秒完成）。
- **浮层清理**：截图前会自动关掉站点自己弹的遮罩（如住建部「验证已过期…停留在当前页」），
  避免遮挡画面。
- **截图失败会降级，不会整张丢**（2026-10 加固）：整页截图（`full_page=True`）遇到超长页面
  （实测 10000px）或 sticky 元素时可能超时，工具会**自动退回可视区截图**并在日志里说明；
  只有可视区也失败才报「截图失败」。板块类采集项（`viewport_shot`）按「标题 + 表格」
  所在容器做元素级截图，元素定位不到再退回可视区。
- **人工环节会挂起**：只有站点**真的**弹出验证码/滑块/登录时才提示，不弹就不打断。
  浏览器使用独立资料目录（`~/.credit_shot_profile/<浏览器>`），登录/验证状态会保留，
  裁判文书网登录一次之后后续运行免登录。
- **浏览器只用一份资料目录，所以同一时刻只能开一个实例**：本轮任务结束（或中止）时
  工具会连同它启动的浏览器进程一起收干净，避免下一次运行因「资料目录被占用」而启动失败。
  若上一次浏览器还活着且带调试端口，下次运行会直接复用它（日志提示「复用已打开的 Edge」）。
- **界面异常不再静默**：程序以 `pythonw` 启动时没有控制台，任何界面异常以前都会被悄悄吞掉，
  表现为「按钮点了没反应」。现在界面异常会同时写入运行日志（红字）并弹窗提示。

1. 首页「认证结果查询」→ 填**企业名称** → 点【查询】

2. 点组织列表里的目标组织 → 再弹极验（人工完成）

### 这个站点的三个「坑」（已在代码里处理）

- **结果页必须再填一次企业名称**。服务端把隐藏域 `#fromIndex` 渲染成字符串
  `"false"`，于是站点 JS 的 `fromIndex == "true"` 判断不成立，
  它不会去取 `#orgNameIndex`，而是读**可见输入框** `#orgName` ——
  而那个框服务端没填值 → 站点直接提示「请输入查询条件!」并**不发起查询**。
- **三处验证码都是极验 v4**（`captcha_id=08c16c99330a5a1d6b7f4371bbd5a978`，
  `product=bind`）。打码服务**没有极验题型**，所以这三段**必须人工**，
  程序会在弹层唤起后挂起等待，点【我已处理，继续截图】继续。
- **弹层在 DOM 上检测不到**：极验 v4 展开与收起时 `.geetest_captcha` /
  `.geetest_box_wrap` 的高度**恒为 0**，`.geetest_box` **恒为 340×386**，
  用尺寸判断会永远误判。程序改为监听「站点调用了 `gt.showCaptcha()`」
  这个信号（页面内注入计数钩子），以此判定弹层已唤起。

### 其它实现要点

- 组织列表行的类名是 **`orgInfoRow` + 数字**（如 `orgInfoRow1`），
  用 `.orgInfoRow` 选择器一个都选不到，必须用 `[class^="orgInfoRow"]` 前缀匹配；
  列表容器 `#orgListDiv` 初始是 `divHidden`，渲染后才变 `divShow`。
- 证书卡片是 `.certInfoSingle`（id `certInfo<n>`），内含隐藏域
  `rzjgId / certNumber / showtemp / certItemOne / etlId`。
- 组织列表所在容器初始带着占位提示「请输入查询条件!」，
  查询成功后只是被隐藏（内容还在），所以**不能**拿它当「查无记录」；
  只有换成别的文案（站点的 `info.msg`）才算真的没有记录。
- 从认监委官网进入时，官网给出的链接是**加速代理地址**，且第一个
  `cx.cnca.cn` 链接指向的是「认证结果综合查询」而不是首页 ——
  入口链因此按**路径**（`/CertECloud/index/index/page`）精确挑链接。

## 已知限制

- 界面是**本地网页**：需要本机装 `fastapi` 与 `uvicorn`（启动脚本会自动装），
  服务只监听 `127.0.0.1`，关掉启动它的命令行窗口即结束服务。

- 住建部详情页需要有效的会话验证。验证过期时详情字段会是「--」，
  工具会点「重新验证」并刷新页面；仍取不到数据时会提示人工完成验证（扫码或滑块）。
- 裁判文书网检索前必须登录。现在可以在【账号密码】里填手机号+密码由程序自动登录；
  不填就仍按老办法在浏览器里手动登录（登录态会保留，下次免登录）。
- 国家企业信用信息公示系统有极验滑块，且需要从弹出的企业列表里选中目标企业，这一步必须人工。
- 军队采购网对高频访问敏感，请不要把节流间隔调到 0。
- 带「日期弹窗」的两种方式，弹窗是从**真实屏幕**上裁下来的，卡片本身是半透明材质，
  因此卡片背景会隐约透出当时屏幕上的内容（这是系统真实观感，不是合成缺陷）。
  日期/时间弹窗位置若实在定位不到，会保留页面原图并在日志里提示，不会丢内容。
- 住建部结果列表在查询后会重排一次，工具会等列表稳定后再点企业名；
  若仍点不进去会自动重试 3 次（每次重新测坐标）。
- 国家企业信用信息公示系统首页加载时会先跳转一次，工具会等搜索框真正可见后才操作。
- 全国认证认可信息公共服务平台的三段验证都是**极验点选**，打码服务不支持该题型，
  **必须人工完成**；程序检测到弹层后会挂起等待，处理完点【我已处理，继续截图】即可。
  若企业在本平台没有任何认证记录，工具会明确提示「无认证记录」而不是当成失败。

## 故障排除

| 现象 | 原因 / 处理 |
|---|---|
| 点【开始截图】没反应 | 看运行日志最后一行是否有红字「✘」；若有，是界面/配置异常，按提示改。日志为空说明根本没点到按钮（可先点【功能自检】验证程序本身正常） |
| 提示「浏览器调试端口未就绪」 | 专用资料目录被上一次遗留的浏览器占用。工具会自动清理后重试一次；仍失败就关掉所有 Edge 窗口再运行 |
| 提示「已中止」 | 任务被手动中止或浏览器被关掉了，重新点【开始截图】即可 |
| 界面卡住不动 | 运行日志最后几行会显示停在哪一步；点【中止】可立即收尾，界面会自动复位 |
| 验证码一直没等到 | 浏览器窗口被挡住或已关闭；把浏览器切到前台完成验证后点【我已处理，继续截图】 |
| 提示「XX 未自动登录：账号、密码未配置」 | 没在【账号密码】里配这个平台。填好后点【保存到本地】；密码框留空表示不修改，不会误清已存密码 |
| 提示「裁判文书网未登录」 | 检索时站点把未登录的访问跳到了登录页。程序会先自动登录；若中途出现**天艾点选**，打码服务官方题型不支持，需要你在浏览器里点一下，然后点【我已处理，继续截图】 |
| 站点提示「环境检测 / Environment Checking」 | 该站正在做 WAF 环境校验，等它放行（工具会等最多 40 秒）；仍不通说明当前网络被判异常，换网络再试 |
| 日志里出现 `takes 1 positional argument but 2 were given` | 实例方法漏写 `self`。跑 `python tools/check_modules.py` 定位（现在会直接报出文件和行号） |

## 界面说明

浏览器里的单页界面（2026-10 重构为本地 Web 版），两栏布局：

```
┌ 渐变品牌条：徽标 · 标题 · 概览副标题 · 右上角状态胶囊 ────────────┐
├ 左栏（宽度随窗口浮动）          ┆ 右栏（自适应）                 │
│ ┌ 查询主体 ────────────────┐   ┆ ┌ 需要截取的内容 ───────────┐ │
│ │ ▐ 单位 │ 人员   ←分段控件│   ┆ │ 站点跳转条（8 个小按钮）  │ │
│ │ 格式提示（自动换行）     │   ┆ │ 站点分组 + 勾选清单        │ │
│ │ ┌─────────────────────┐ │   ┆ │ 右上角：已选 N/28、全选    │ │
│ │ │ 输入框（随窗口伸展）│ │   ┆ └───────────────────────────┘ │
│ │ └─────────────────────┘ │   ┆ ┌ 运行日志 ──────────────────┐ │
│ └──────────────────────────┘   ┆ │ 彩色分级：成功绿/失败红/  │ │
│ ┌ 输出设置 ────────────────┐   ┆ │ 提示琥珀/信息蓝            │ │
│ │ 保存目录 / 浏览器 /      │   ┆ └───────────────────────────┘ │
│ │ 截图方式 / 节流间隔      │   ┆                               │
│ └──────────────────────────┘   ┆                               │
├ 底部按钮条：开始截图 · 继续 · 跳过 · 中止 · 自检 · 浏览器打开 · 目录 ┤
└ 状态栏：当前状态 ● ────────────────── 截图方式说明 ─────────────┘
```

界面由浏览器渲染，配色沿用桌面版的设计令牌，跨 Windows 版本观感一致。

### 界面与引擎的通信

| 方向 | 方式 | 说明 |
|---|---|---|
| 界面 → 引擎 | REST | `/api/run` 启动，`/api/control/{resume\|skip\|stop}` 下指令 |
| 引擎 → 界面 | SSE | `/api/events` 实时推送日志行、状态变化、单项结果 |

引擎跑在后台线程里（Playwright 是同步 API，不能跑在事件循环里），
所以日志先进入事件总线，再由 SSE 推给页面。

### 启动方式（不弹命令行黑框）

| 方式 | 效果 |
|---|---|
| 双击 `启动.vbs` | **推荐**：零黑框，自动起服务并打开浏览器界面 |
| 双击 `启动.bat` | 首次用：装依赖时会看到几秒黑框，装完自动转 `启动.vbs` |
| `python main.py` | 调试用，保留控制台看报错 |

无控制台启动时若发生异常，会写入同目录 `启动错误.log` 并弹窗提示。

> 服务只监听 `127.0.0.1`（本机回环），局域网内其它机器访问不到，
> 账号密码与截图都留在本机。

## 与 `site_shot/` 的区别

- `site_shot/`（第一阶段）：只按站点全屏截图 + 自动展开日期/日历弹窗，不输入任何查询内容。
- `credit_shot/`（本工具）：输入查询内容、等结果刷新才截图，按站点批量采集 30 类信用记录；
  截图方式可选原生整页或整屏+日期弹窗；查询主体支持**单位 / 人员两种互斥模式**。
